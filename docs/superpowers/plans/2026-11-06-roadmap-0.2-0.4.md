# Релизы 0.2–0.4: данные, CGM и интеграции — план реализации

> **Для агентов:** выполнять по шагам, отмечая чекбоксы. Основной источник требований —
> `docs/research/roadmap-2026-11-06.md`. После каждого блока — сборка, тесты, коммит.

**Goal:** превратить MVP-дневник глюкозы в полноценный дневник самоконтроля: честные метрики,
данные кроме глюкозы, CGM/AGP, шифрование и интеграции — не выходя за рамки «не медизделие».

**Architecture:** единое событие `events` + типизированные таблицы (глюкоза, инсулин, углеводы,
вес, давление, кетоны, HbA1c). Room 2.8 + миграции. Домен — чистый Kotlin, UI — Compose,
экспорт — PDF/CSV. CGM — импорт из xDrip/уведомлений/Health Connect, без собственных BLE-драйверов.

**Tech Stack:** Kotlin 2.2.21, Compose, Room 2.8.5 + KSP 2.2.21-2.0.5, SQLCipher 4.20.0 (0.3),
DataStore/Keystore, WorkManager, ZXing (0.4).

**Spec:** `docs/research/roadmap-2026-11-06.md`

## Global Constraints

- Приложение **не медизделие**: никаких расчётов доз, ICR/ISF, прогнозов гипогликемии,
  диагнозов и «степени компенсации».
- Канонические единицы: глюкоза — целые мг/дл; инсулин — целые миллиединицы (0,001 U);
  углеводы — 0,1 г; вес — граммы; кетоны — 0,1 ммоль/л; HbA1c — ммоль/моль + %.
- Время события — UTC epoch millis + `zone_offset_min`; отображать в локальной зоне.
- У каждого события: `source` (manual/meter/cgm/import/health_connect), `external_id`,
  `deleted_at` для мягкого удаления.
- Не хранить вычисленные метрики в БД.
- minSdk 26, targetSdk 36, JDK 17. Русский UI, тёмная тема, Material 3.
- 0.2 полностью офлайн: без INTERNET, Health Connect и сетевых разрешений.
- Любая миграция БД проверяется тестом; `exportSchema = true`.
- Существующие данные пользователя (таблица `glucose_entries`) не теряются.

## Review Focus

- **Границы единиц:** 5,6 ммоль/л не должно стать 56 или 560 мг/дл; 0,5 U инсулина — 500 milliU.
- **Границы диапазона:** 70 и 180 мг/дл входят в диапазон; 54 и 250 — пороги тяжёлых уровней.
- **Старые данные:** после миграции все записи глюкозы на месте, даты и заметки сохранены.
- **Пустые и редкие данные:** метрики не делят на ноль, GMI/ADAG не выдаются за лабораторный HbA1c.
- **Удаление:** мягко удалённое событие исчезает из таймлайна, графиков и экспорта, но не ломает БД.

## Release 0.3 — «CGM, AGP и защита» (контрольные точки)

1. **CGM-импорт:** xDrip `com.eveningoutpost.dexdrip.BgEstimate`, `NotificationListenerService`,
   локальный HTTP `127.0.0.1:17580/sgv.json`, Health Connect как резерв. Дедупликация по
   `source + external_id`, честный статус «нет данных».
2. **Модель CGM:** шаг 1–5 минут, `specimen`, `trend`, `quality`; отдельный поток от ручных замеров.
3. **AGP:** перцентили 5/25/50/75/95 за 14 дней при ≥70% активности; «предварительный» режим.
4. **Метрики CGM:** TIR/TBR/TAR уровней 1/2, CV, GMI, гипо-эпизоды ≥15 минут, ночное окно.
5. **Защита:** SQLCipher + Keystore + `BiometricPrompt`; шифрованный экспорт/импорт (ключ не в бэкапе).
6. **Напоминания:** WorkManager + неточные alarm по умолчанию; точные — только как опция.
7. **PDF v3:** AGP + TIR-бар + суточные профили + инсулин/углеводы.
8. **Тесты:** парсер xDrip на сохранённых JSON, дедупликация, миграция на зашифрованную БД.

## Release 0.4 — «Интеграции и еда» (контрольные точки)

1. **Health Connect:** запись глюкозы/давления/веса, чтение веса/давления/активности;
   Play-декларация, минимальные разрешения.
2. **Nightscout:** импорт `entries`/`treatments`, экспорт как опция, токен в Keystore.
3. **Еда:** локальные частые блюда, порции, углеводы; OFF по штрихкоду, кэш, ZXing, атрибуция ODbL.
4. **Недельная сводка:** 7 дней, тренд, полнота — в приложении и PDF.
5. **Места установки:** карта тела, ротация, напоминания.
6. **FHIR-экспорт (alpha):** `Observation` для глюкозы/давления/веса/HbA1c.
7. **Цикл (beta, по желанию):** отметка фазы без прогнозов.
